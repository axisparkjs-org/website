# Built-in authenticators

Reading and parsing credentials is the same code in every application, and it is easy to get wrong: the case of the scheme, the Base64 decoding of Basic credentials or the timing-safe comparison of API keys. `@axisparkjs/security` includes base authenticators for the most common HTTP credentials, and `@axisparkjs/security-jwt` adds a `JwtAuthenticator` that verifies JSON Web Tokens. The application only writes how a credential becomes a principal.

The built-in classes extend `Authenticator`, so they work with the `all` and `selected` strategies, the dependency injection container and the existing guards. Custom authenticators that extend `Authenticator` keep working with no changes.

The HTTP authenticators declare `static transports = [ExecutionTransport.Http]`, so they are skipped for other transports. They read the request through a structural type, so `@axisparkjs/security` does not depend on `@axisparkjs/http`.

## `CredentialAuthenticator`

Every built-in authenticator extends `CredentialAuthenticator<TCredential, TPrincipal>`, an abstract class that splits authentication into two steps:

- `extract(context)` reads the credential from the execution context. It returns `undefined` when there is no credential.
- `validate(credential, context)` returns the principal, or `undefined` when the credential is not valid.

`authenticate` calls both steps, and `validate` is not called when there is no credential. Extend `CredentialAuthenticator` directly to support another credential, such as a cookie or a custom header:

```ts title="auth/session-cookie-authenticator.ts"
import { Injectable } from '@axisparkjs/di';
import { ExecutionContext, ExecutionTransport } from '@axisparkjs/engine';
import { HttpContext } from '@axisparkjs/http';
import { CredentialAuthenticator } from '@axisparkjs/security';

@Injectable()
export class SessionCookieAuthenticator extends CredentialAuthenticator<string, Principal> {
    static readonly transports = [ExecutionTransport.Http];

    constructor(private readonly sessions: SessionService) {
        super();
    }

    protected extract(context: ExecutionContext): string | undefined {
        return (context as HttpContext).request.getCookie('session_id');
    }

    protected async validate(sessionId: string): Promise<Principal | undefined> {
        return this.sessions.findPrincipal(sessionId);
    }
}
```

## Bearer tokens

`BearerAuthenticator` reads the token of the `Authorization: Bearer <token>` header. The scheme is compared case-insensitively, and a header with another scheme is ignored.

```ts title="auth/token-authenticator.ts"
import { Injectable } from '@axisparkjs/di';
import { BearerAuthenticator } from '@axisparkjs/security';

@Injectable()
export class TokenAuthenticator extends BearerAuthenticator<Principal> {
    constructor(private readonly tokens: TokenService) {
        super();
    }

    protected async validate(token: string): Promise<Principal | undefined> {
        return this.tokens.findPrincipal(token);
    }
}
```

## Basic credentials

`BasicAuthenticator` reads the `Authorization: Basic <base64>` header ([RFC 7617](https://www.rfc-editor.org/rfc/rfc7617)), decodes it as UTF-8 and splits it at the first `:`. A header that is not valid Base64 or has no `:` is ignored.

```ts title="auth/user-basic-authenticator.ts"
import { Injectable } from '@axisparkjs/di';
import { BasicAuthenticator, BasicCredentials } from '@axisparkjs/security';

@Injectable()
export class UserBasicAuthenticator extends BasicAuthenticator<Principal> {
    constructor(private readonly users: UserService) {
        super();
    }

    protected async validate({ username, password }: BasicCredentials): Promise<Principal | undefined> {
        const user = await this.users.findByUsername(username);
        if (!user || !(await this.users.verifyPassword(user, password))) return undefined;

        return { id: user.id, role: user.role };
    }
}
```

Store password hashes, not passwords, and verify them with a password hashing library such as `argon2` or `bcrypt`.

## API keys

`ApiKeyAuthenticator` reads the key from the `X-API-Key` header by default. Set the `protected readonly source` property to read it from another header or from a query parameter. When both `header` and `query` are set, the header is read first.

```ts title="auth/client-api-key-authenticator.ts"
import { Injectable } from '@axisparkjs/di';
import { ApiKeyAuthenticator, ApiKeySource } from '@axisparkjs/security';

@Injectable()
export class ClientApiKeyAuthenticator extends ApiKeyAuthenticator<Client> {
    protected readonly source: ApiKeySource = { header: 'x-api-key', query: 'api_key' };

    constructor(private readonly clients: ClientService) {
        super();
    }

    protected async validate(apiKey: string): Promise<Client | undefined> {
        return this.clients.findByApiKey(apiKey);
    }
}
```

:::warning

Query parameters are often written to access logs and browser history. Prefer the header, and accept a query parameter only when the client cannot send headers.

:::

### Compare secrets with `safeCompare`

Compare API keys and passwords with `safeCompare(a, b)`, never with `===`. `===` stops at the first different character, so the response time can reveal how much of a secret is correct. `safeCompare` hashes both values with SHA-256 and compares them with `crypto.timingSafeEqual`, so the time does not depend on the content or the length of the values.

```ts
import { safeCompare } from '@axisparkjs/security';

const client = clients.find((candidate) => safeCompare(apiKey, candidate.apiKey));
```

## JSON Web Tokens

`JwtAuthenticator` is in its own package, so applications that do not use JWT do not install [`jose`](https://github.com/panva/jose), the library it uses to verify the tokens.

```bash
npm install @axisparkjs/security-jwt
```

`JwtAuthenticator` extends `BearerAuthenticator`. Set the verification options with the `protected readonly options` property, and override `toPrincipal` to map the verified claims to the principal. By default, the claims are the principal.

```ts title="auth/app-jwt-authenticator.ts"
import { Injectable } from '@axisparkjs/di';
import { JwtAuthenticator, JWTPayload } from '@axisparkjs/security-jwt';

@Injectable()
export class AppJwtAuthenticator extends JwtAuthenticator<Principal> {
    protected readonly options = {
        secret: process.env.JWT_SECRET as string,
        algorithms: ['HS256'],
        issuer: 'my-app',
        audience: 'my-api'
    };

    protected async toPrincipal(claims: JWTPayload): Promise<Principal> {
        return { id: claims.sub as string, role: claims.role as Principal['role'] };
    }
}
```

The token is rejected when its signature is not valid, its algorithm is not in `algorithms`, it has expired (`exp`), it is not valid yet (`nbf`), or its `iss` or `aud` claims do not match the options. A rejected or malformed token returns `undefined`, so the next authenticator can run and the guards throw `AuthenticationError` for secured handlers. Return `undefined` from `toPrincipal` to reject a valid token, for example when its subject no longer exists.

Set exactly one of `secret`, `publicKey` or `jwksUri`. An invalid configuration, such as an empty `algorithms` list or no key, throws an error on the first request with a token instead of rejecting every token silently.

For tokens issued by an identity provider, use its JSON Web Key Set:

```ts
protected readonly options = {
    jwksUri: 'https://auth.example.com/.well-known/jwks.json',
    algorithms: ['RS256'],
    issuer: 'https://auth.example.com/',
    audience: 'my-api'
};
```

Signing tokens, for example in a login endpoint, is left to the application. You can use `SignJWT` from `jose`.

## Combine several authenticators

Register the authenticators in the order they should run. The first one that returns a principal wins, and `context.authenticationMethod` contains its class:

```ts title="app.ts"
app.use(
    SecurityPlugin,
    SecurityPluginOptionsFactory.create({
        authenticator: {
            strategy: 'selected',
            selected: [AppJwtAuthenticator, UserBasicAuthenticator, ClientApiKeyAuthenticator]
        }
    })
);
```

The [show-your-credentials sample](https://github.com/axisparkjs/axispark/tree/main/samples/show-your-credentials) runs Basic, API key and JWT authentication in the same application.
