# Installation

Thanks to AxiSpark.js, you can easily install the Schedule Plugin in your project. Follow the steps below to get started.

## 1. Install the Schedule Plugin

You can use npm or any other package manager to install the Schedule Plugin. Run the following command in your project directory:

```
npm install @axispark/schedule
```

## 2. Import the Schedule Plugin

Once the installation is complete, you can import the Schedule Plugin into your project. Add the following line to your code:

```ts
import { AxiSparkFactory } from '@axisparkjs/core';
import { SchedulePlugin } from '@axisparkjs/schedule';

export const app = AxiSparkFactory.create({
    ...
});

app.use(SchedulePlugin);
```

## 3. Configure the Schedule Plugin

The Schedule Plugin works without configuration. Its `lockStore` option is the [store](../getting-started/stores) of the locks of the [exclusive jobs](./exclusive-jobs). It defaults to `MemoryStore()`, which only coordinates the jobs of one process. Its `shutdownTimeout` option is the maximum time to wait for the running jobs when the application stops: see [Stopping the scheduler](./managing-a-job#stopping-the-scheduler). Pass the options with `SchedulePluginOptionsFactory`:

```ts
import { RedisStore } from '@axisparkjs/redis';
import { SchedulePlugin, SchedulePluginOptionsFactory } from '@axisparkjs/schedule';

app.use(SchedulePlugin, SchedulePluginOptionsFactory.create({ lockStore: RedisStore('MAIN'), shutdownTimeout: 20_000 }));
```

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `lockStore` | `StoreProvider<'lock'>` | `MemoryStore()` | The provider of the lock store of the exclusive jobs, called when the plugin starts. |
| `shutdownTimeout` | `number` | `25000` | The maximum time to wait for the running jobs when the application stops, in milliseconds. `0` does not wait. |
