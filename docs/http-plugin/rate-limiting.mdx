# Rate limiting

The HTTP plugin can limit requests with a sliding time window. It is disabled by default. Enable it in the plugin options to apply the configured defaults to every endpoint:

```ts
HttpPluginOptionsFactory.create({
    rateLimit: true,
    rateLimitOptions: {
        ttl: 60_000,
        limit: 100,
        message: 'Too many requests. Please try again later.'
    }
});
```

`ttl` is the window duration in milliseconds, and `limit` is the maximum number of requests from one IP address to one endpoint during that window. The limit applies to the route, not to the requested URL: `GET /users/1` and `GET /users/2?active=true` count against the same limit of `GET /users/:id`. If `rateLimitOptions` is omitted, the defaults are 60 seconds and 100 requests. A message callback receives the milliseconds remaining until the oldest request expires.

Use `@RateLimit()` on a controller or handler to override those defaults. Partial handler options use the global defaults for values they omit:

```ts
import { Controller, Get } from '@axisparkjs/http';
import { RateLimit } from '@axisparkjs/engine';

@RateLimit({ ttl: 60_000, limit: 20 })
@Controller('auth')
export class AuthController {
    @Get('login')
    @RateLimit({ limit: 5 })
    login() {
        return { message: 'Login endpoint' };
    }
}
```

Use `@NoRateLimit()` to exclude a controller or handler. A handler decorator takes precedence over the controller decorator, so it can also opt back in to rate limiting:

```ts
import { Controller, Get } from '@axisparkjs/http';
import { NoRateLimit, RateLimit } from '@axisparkjs/engine';

@NoRateLimit()
@Controller('health')
export class HealthController {
    @Get()
    check() {
        return { status: 'ok' };
    }

    @Get('sensitive')
    @RateLimit({ limit: 5 })
    sensitive() {
        return { status: 'limited' };
    }
}
```

Requests over the limit receive `429 Too Many Requests`, a JSON body containing `message`, and a `Retry-After` header in seconds. The default message is `Too many requests. Please try again later.` Decorators have no effect while `rateLimit` is `false`.

The requests are counted by `RateLimitProcessor` in `@axisparkjs/engine`, with the same algorithm for every transport: the HTTP plugin only identifies the client by its IP address. See [Rate limits](../engine-system/rate-limits) in the engine documentation to add rate limits to other transports.

## Sharing the limits between instances

The requests are counted in memory by default, so each instance of the application has its own limits: with three instances behind a load balancer, a client can make three times as many requests. Set `rateLimitOptions.store` to a shared [store](../getting-started/stores), such as `RedisStore` from `@axisparkjs/redis`, to count the requests of every instance together:

```ts
import { RedisPlugin, RedisPluginOptionsFactory, RedisStore } from '@axisparkjs/redis';

app.use(RedisPlugin, RedisPluginOptionsFactory.create({ connections: [{ name: 'MAIN', url: 'redis://localhost:6379' }] }));
app.use(
    HttpPlugin,
    HttpPluginOptionsFactory.create({
        rateLimit: true,
        rateLimitOptions: {
            ttl: 60_000,
            limit: 100,
            store: RedisStore('MAIN', { prefix: 'myapp:' })
        }
    })
);
```

The store is created when the plugin starts. The responses, the `Retry-After` header and the decorators do not change. When the Redis connection is not ready, for example while it reconnects, the store rejects the requests with a `RedisStoreConnectionNotReadyError`, returned as `500 Internal Server Error`, instead of making them wait for the connection.

## Behind a proxy

Limits are applied per client IP address, which is the value of `request.ip`. Behind a reverse proxy or a load balancer, that address is the address of the proxy unless the [`trustProxy` option](./installation#running-behind-a-proxy) is set, so every client behind the same proxy shares one limit and a few clients can block the rest. Set `trustProxy` when the application runs behind a proxy:

```ts
HttpPluginOptionsFactory.create({
    trustProxy: 1,
    rateLimit: true
});
```
