# Installation

Thanks to AxiSpark.js, you can easily install the Http Plugin in your project. Follow the steps below to get started.

## 1. Install the Http Plugin

You can use npm or any other package manager to install the Http Plugin. Run the following command in your project directory:

```
npm install @axispark/http
```

## 2. Import the Http Plugin

Once the installation is complete, you can import the Http Plugin into your project. Add the following line to your code:

```ts
import { AxiSparkFactory } from '@axisparkjs/core';
import { HttpPlugin, HttpPluginOptionsFactory } from '@axisparkjs/http';

export const app = AxiSparkFactory.create({
    ...
});

app.use(HttpPlugin, HttpPluginOptionsFactory.create({
    // Configuration options
}));
```

## 3. Configure the Http Plugin

Http Plugin offers a `HttpPluginOptionsFactory` class that allows you to configure the plugin with various options. The `HttpPluginOptionsFactory.create()` method accepts an object with the following properties:

```ts name="http-plugin-options.ts"

    type: VersionType.Custom;

     * The timeout duration in milliseconds.

    time: number;

    message?: string | ((time: number) => string);
```

### Listening address

By default, the HTTP server listens on every network interface with both adapters, as Node.js does: on `::` when IPv6 is available, and on `0.0.0.0` otherwise. This is what an application needs inside a container (Docker, Kubernetes), where the traffic and the health checks of the orchestrator do not arrive through the loopback interface.

Set `host` to listen on a single address, for example to accept only the connections from the same machine:

```ts
app.use(HttpPlugin, HttpPluginOptionsFactory.create({ port: 3000, host: '127.0.0.1' }));
```

The start message of the plugin shows the address and the port returned by the server, such as `Plugin started. Listening on [::]:3000` or `Plugin started. Listening on 127.0.0.1:3000`.

> Before this option existed, the Fastify adapter listened only on `localhost`. If your application relied on it, set `host: '127.0.0.1'`.

### Running behind a proxy

Behind a reverse proxy or a load balancer, the address of the socket is the address of the proxy, not the address of the client. Set `trustProxy` so that `request.ip` returns the client address from the `X-Forwarded-For` header:

```ts title="app.ts"
app.use(HttpPlugin, HttpPluginOptionsFactory.create({ port: 3000, trustProxy: 1 }));
```

`trustProxy` accepts the same values in the Express and Fastify adapters:

| Value | Description |
| --- | --- |
| `false` | Default. No proxy is trusted, and `request.ip` is the address of the socket. |
| `true` | Every proxy is trusted, and `request.ip` is the leftmost address of `X-Forwarded-For`. Use it only when the application cannot be reached without the proxy, because clients can send any value in the header. |
| A number | The number of proxies between the client and the application. For example, `1` when there is a single load balancer in front of the application. |
| A string or string array | Addresses or subnets of the trusted proxies, such as `'10.0.0.0/8'`, `['10.0.0.1', '10.0.0.2']` or the `'loopback'`, `'linklocal'` and `'uniquelocal'` names. A string can contain several values separated by commas. |

The value is passed to the `trust proxy` setting of Express and to the `trustProxy` server option of Fastify. The [host routing](./controllers) of the controllers and the versioning keep reading the `Host` and version headers of the request, so `trustProxy` does not change them.

:::warning
Trust only the proxies you control. With `trustProxy` set, a client that reaches the application without going through a trusted proxy can send its own `X-Forwarded-For` header and choose the address that the application sees.
:::

### Static files with Fastify

The Fastify adapter serves the files of the `public` folder of the `basePath` of the application, but only when the folder exists, so an API without static files does not register a static route. Set `staticFiles` to choose it explicitly, and `staticFilesOptions` to change the folder and the URL prefix:

```ts title="app.ts"
import { HttpPluginOptionsFactory } from '@axisparkjs/http-fastify';

app.use(
    HttpPlugin,
    HttpPluginOptionsFactory.create({
        staticFiles: true, // Always serve them; `false` never serves them.
        staticFilesOptions: { root: 'assets', prefix: '/assets/' } // Relative to the basePath. Defaults: `public` and `/`.
    })
);
```

The file results (`HttpResults.File()`) work with every value, because they send the file from its own folder. The Express adapter does not serve static files.

> Set `healthChecks: true` to expose the `/health`, `/health/liveness` and `/health/readiness` endpoints. Check the [Health Checks](../getting-started/health-checks) page for more information.
