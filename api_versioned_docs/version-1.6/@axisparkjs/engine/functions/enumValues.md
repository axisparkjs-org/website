# Function: enumValues()

> **enumValues**(`enumOrValues`): (`string` \| `number`)[]

Returns the values of a TypeScript enum, without the reverse mappings of the numeric enums, or the values of an array.

## Parameters

### enumOrValues

[`EnumLike`](../type-aliases/EnumLike.md)

The enum or the array of values.

## Returns

(`string` \| `number`)[]

The allowed values.
