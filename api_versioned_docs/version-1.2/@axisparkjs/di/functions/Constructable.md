# Function: Constructable()

> **Constructable**(...`metadataKeys`): `ClassDecorator`

A decorator that marks a class as constructable, allowing it to be instantiated by the dependency injection container.

## Parameters

### metadataKeys

...[`MetadataKey`](../../common/classes/MetadataKey.md)[]

An array of metadata keys to define on the class.

## Returns

`ClassDecorator`

A class decorator.
